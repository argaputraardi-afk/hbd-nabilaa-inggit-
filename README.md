# Website Ulang Tahun Nabila Inggit 💗

Website ucapan ulang tahun dengan desain seperti versi sebelumnya, tetapi menggunakan tema pink.

## Isi folder
- `index.html` — halaman utama
- `style.css` — desain dan warna pink
- `script.js` — tombol buka pesan, kejutan, dan musik
- `assets/` — tempat file lagu

## Menambahkan lagu
Letakkan file audio yang kamu miliki dengan nama:

`assets/shape-of-my-heart.mp3`

Lagu akan mulai diputar setelah tombol "Buka pesan" ditekan.

## Upload ke GitHub
1. Buat repository baru di GitHub.
2. Upload semua isi folder ini.
3. Aktifkan GitHub Pages melalui Settings → Pages.
